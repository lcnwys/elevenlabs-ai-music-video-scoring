Eleven Music Director · v0.1

专业音乐导演 Skill + 可本地运行的 AI 音乐工作台。核心目标：用户无需懂乐理，就能从自然语言、原创歌词、情绪短片和视频获得 ElevenLabs 音乐生成请求，并保留创作记录。

打开工作台查看专家技能定义

先打开体验

双击 index.html 可体验离线模板草案、JSON 编曲计划示例和创作资产记录。离线预览没有真实 AI 语义理解，也无法实际调用音乐 API。

启动真正的音乐生成

在本目录执行（Mac/Linux）：

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# 编辑 .env：填 ELEVENLABS_API_KEY
# 需要 AI 导演时再填 OPENAI_API_KEY
uvicorn server:app --host 127.0.0.1 --port 8765

Windows PowerShell 将激活命令替换为 .venv\Scripts\Activate.ps1，复制命令为 Copy-Item .env.example .env。在浏览器打开 http://127.0.0.1:8765。

ElevenLabs Music API 需要付费账号。本包未包含用户 API Key，也未执行真实音乐生成、产生费用。

范围之外（不冒充已完成）

自动读取当前 ChatGPT 会话、新闻检索、电影镜头级语义识别、自动 Scribe + Auto Ducking、视频成片导出、音乐账号多租户管理、持久化服务端版本库尚未接入。当前视频直配乐由 ElevenLabs 官方模型执行；想达到导演级镜头控制，仍需另建视频时间轴解析、标注和后期工作流。

开发验证与安全

执行 python -m pytest -q，本版提供 11 个不产生 API 费用的自动测试。开发服务器只绑定本机，生产上线前必须增加身份认证、配额、计费、上传扫描和异步任务队列。API Key 只在服务端 .env 中保存；请勿上传 .env 文件。

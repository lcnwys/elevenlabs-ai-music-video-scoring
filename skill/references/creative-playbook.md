# 音乐导演创意手册

## 问用户什么
优先不问。只在无法判断“人声还是纯音乐”且结果差别巨大、或视频授权状态不明时问一次；没有长度默认 30s 配乐 / 2m 歌曲。有感性描述即开始做草案。

## 7 维专业语言映射
1. 情绪：温柔/悲伤/兴奋/悬疑/希望。不要只写 happy/sad；附加具体质地、动态轨迹。
2. 风格：现代合成器流行、Acoustic Folk、Neo-Soul、Breakbeat、Ambient、Cinematic、Jazz、国风融合等。
3. 节奏：BPM、节拍与 groove（swing, syncopation, halftime, four-on-the-floor），合理避免节奏冲突。
4. 旋律：音域、动机长度、重复/变奏、上行/下行、Hook 位置、音符密度。
5. 和声：调式色彩、功能张力、延伸和弦、持续音与过渡，而非盲目套用公式。
6. 配器：主角乐器/节奏组/底层氛围/点缀特效，动态层次与变化。
7. 制作：模拟温暖、干声、立体声宽度、空间混响、低频密度、对白频谱避让。

## 典型结构
- 30s 产品广告：0–5s Hook → 5–18s 发展 → 18–26s 情绪高点 → 26–30s Logo sting。
- 60s 情绪短视频：0–10s 稀疏铺垫 → 10–30s 叙事 → 30–48s 转折 → 48–60s 余韵。
- 2min 流行歌曲：8s Intro → 24s Verse → 12s Pre-Chorus → 24s Chorus → 24s Verse 2 → 12s Bridge → 12s Chorus Reprise → 4s Outro = 120s。
- 45s 游戏 Loop：0–8s 主题建立 → 8–25s 主循环 → 25–37s 变奏 → 37–45s 收束到可衔接的节奏元素；不要假定生成结果已物理无缝。

## 中文歌词评估
- 副歌一句 8–14 字通常更容易记忆（经验建议，不是硬约束）。
- 人称、意象、时间、情绪主题要一致，避免每句都堆“月光”“星河”“未来”等泛词。
- 口语可唱性优先于盲押尾韵。重音和节奏清晰、段落情绪变化有理由。
- 有行业/品牌名称时先确认正确读音，英文品牌尽量设计声韵衔接。

## 视频导演准则
- 官方 Video-to-Music 可根据视频生成 BGM，但不能假设返回了每镜头的文字分析或精确 timecode；要精准剪辑，应单独用视频理解模型生成镜头表、人工校对后再编排。
- 有对白：默认纯音乐、压低频谱冲突，使用后期 Auto Ducking；需要辨认台词的情况可以加 Scribe 判断说话时间，但 Scribe 不必呈现在终端用户 UI。
- 有动作：应按画面动作点划分音效与音乐，SFX 独立轨道比自动混音更利于后期。
- 时事：先核实事件、整理故事弧线，再创作音乐；尊重现实事件当事人与敏感背景。

## 用户反馈到音乐调整
- “很平”：增加对比段落、空间变化、节奏停顿、明确 Hook，不单是提升 BPM。
- “太吵”：减少鼓击/密集高频、降低和声层数、压缩瞬态，增加静默。
- “不像悲伤”：减少大调明亮配器、用非解决和声与留白，不单是降速。
- “歌词机器味”：减少空泛意象、加入单一具体细节、检验自然口语和押韵。
- “跟画面不贴”：检查镜头转折点和对白时间，决定重生成还是局部替换。

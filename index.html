步骤能力说明

Video-to-Music API

POST /v1/music/video-to-music
Content-Type: multipart/form-data
videos[]: video.mp4
model_id: music_v2_5
description: ...
tags[]: cinematic
add_sfx / separate_tracks /
use_audio_as_reference: true|false

上面为字段示意，实际请求使用后端 FormData，不会在浏览器保存 API Key。

什么时候值得用高级模式？

简单 PromptComposition Plan
快速试风格、短 BGM、灵感探索中文歌词、副歌、桥段、精准分段
模型决定较多结构细节逐段设置风格、歌词与时长
快速迭代整首可为后续 Inpainting 建立可编辑结构

官方硬限制

最多 30 个 chunks；每段 3–120 秒；整首 3–600 秒。风格标签必须为英文；歌词可用中文。

在 `text` 里写 `[Verse]`、`[Chorus]` 和实际歌词；全段声线与配器写进 `positive_styles`。简单 Prompt 与 Composition Plan **不能同时传入**。

`/v1/music/plan` 官方接口不消耗音乐积分，但有限流；生成实际音频仍会产生相应消耗。

本地启动

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# 编辑 .env，填好 Key
uvicorn server:app --host 127.0.0.1 --port 8765

打开 http://127.0.0.1:8765。不要把开发服务器直接部署到公网；上线前需鉴权、限流、账单预算、上传安全检测、任务队列及隐私存储策略。
